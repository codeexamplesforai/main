Rose/red = L4 / HIGH priority / risk ≥0.7 / errors. Emerald = L5 / success / ACTIVE / risk <0.4 / ACCOUNT. Orange = DERIVED. Sky/teal = GEOGRAPHIC/CURRENCY.

## Practical tips for running this sequence

- **File handoff:** after each turn, save the output to `aml-demo.html` (overwrite). For the next prompt, paste the entire content of that file where it says `[PASTE OUTPUT FROM PROMPT N]`.
- **If a model truncates** (cuts off mid-file): say in the next message "continue from where you left off, output the rest of the file only, starting at line X". Then stitch the two parts manually.
- **If a model breaks earlier functionality:** revert to the previous step's output, repeat the prompt with the extra instruction "Do not remove or alter any code from previous turns. Only add/edit what this turn requests."
- **Test after each prompt:** open the file in a browser. Make sure (a) all 18 nav buttons still work, (b) no console errors, (c) the new feature this turn added is visible and interactive. If broken, fix before moving on.
- **Skipping pages:** if you don't care about, say, Sandbox or Feedback Loop, skip Prompt 12 — but then drop the sidebar entries `sandbox` and `feedback` from Prompt 1 too, or those nav buttons will go to empty placeholders.
- **Bigger models:** if you switch to a frontier model mid-sequence, you can merge two or three prompts into one to save turns.
